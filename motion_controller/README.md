# Контроллер механизмов Smart Mixer

Отдельный PlatformIO-проект для Arduino UNO R4 Minima. Исходный скетч перенесён
в `src/main.cpp`, аппаратные модули — в `include/`.

Из этого каталога:

```sh
pio run
pio run -t upload
pio device monitor
```

Порт — `/dev/ttyACM0`, скорость — `115200`, строки команд завершаются LF.
При запуске выполняется поиск верхнего концевика. Насосы, калибровка и ручное
движение доступны через Serial; команда `help` выводит список команд.

## USB-интерфейс на ноутбуке

Для интерфейса ноутбука есть окружение `desktop_usb`: управление по USB
как в обычной сборке, но homing запускается только командой `home`.
Дополнительно эта сборка принимает рецепты с двумя слоями и движением штока
по таблице высоты. Исполнитель обрабатывает STOP между микрошагами и имеет
watchdog 2 секунды; сервисные home/move остаются блокирующими.
Сборка/загрузка: `pio run -e desktop_usb -t upload`.
Инструкция приложения: [desktop_controller](../desktop_controller/README.md).

## Отдельная UART-диагностика CrowPanel

Для проверки с CrowPanel выбрать окружение `uart_diagnostics`:

```sh
pio run -e uart_diagnostics
pio run -e uart_diagnostics -t upload
pio device monitor -e uart_diagnostics
```

Эта прошивка не запускает homing, не пишет EEPROM и не принимает исполнительные
команды. Насосные выходы выключены, STEP не генерируется, драйвер отключён через
EN. Проверять без нагрузки, требующей удержания двигателем. Концевик читается
с D9; положение остаётся unknown, потому что homing не выполняется.

UART на D0/RX и D1/TX работает на 19200 8N1. Адаптер использует асинхронный
Renesas FSP SCI2: не вызывать Serial1.begin/write одновременно с ним.
USB Serial 115200 выводит статистику при наличии свободного буфера.
На уровне кода реализованы HELLO/OPEN/PING/GET_STATUS и истечение сессии;
работа на реальном стенде пока не подтверждена. Обычное окружение
`uno_r4_minima` остаётся прежней механической прошивкой и UART не обслуживает.

OLED-модуль и зависимость U8g2 удалены.
