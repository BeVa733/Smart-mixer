# Контроллер механизмов Smart Mixer

Отдельный PlatformIO-проект для Arduino UNO R4 Minima. Исходный скетч перенесён
в `src/main.cpp`, аппаратные модули — в `include/`.

Из этого каталога:

```sh
pio run
pio run -t upload
pio device monitor
```

Порт — `/dev/ttyACM0`, скорость — `115200`, строки команд завершаются LF.
При запуске выполняется поиск верхнего концевика. Насосы, калибровка и ручное
движение доступны через Serial; команда `help` выводит список команд.

UART-связь с ESP32 пока не реализована. OLED-модуль и зависимость U8g2 удалены.
