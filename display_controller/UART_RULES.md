# Правила работы с UART CrowPanel Basic 7″ Rev3

Применяется к нашей Elecrow CrowPanel ESP32-S3 Basic 7″, DIS08070H, Rev3.
Инструкции для Advance и ESP32-P4 к этой плате не переносить.

## Главное правило

Внешний UART — штатный интерфейс панели. Он использует общие сигнальные
выводы с USB-UART CH340C. Работа с внешним устройством и прошивка/USB-отладка
проводятся раздельно. Необходимость переделки платы заранее не установлена:
сначала проверяется штатное подключение по порядку производителя.

## Подключение

| Сигнал | CrowPanel | Arduino UNO R4 Minima |
|---|---|---|
| Передача от панели | TX, GPIO43, J10/2 | D0/RX, Serial1 |
| Передача к панели | RX, GPIO44, J10/1 | D1/TX, Serial1 |
| Общая земля | J10/4, GND | GND |

TX соединяется с RX другой платы через согласование уровней. UNO R4 Minima
имеет логику 5 В, ESP32 — 3,3 В; прямое соединение Arduino TX с ESP RX запрещено.
Для начального стенда выбран BSS138, но его пригодность для этого UART
подтверждается проверкой уровней и двусторонней передачи на реальном модуле.

J10/3 по схеме Rev3 — **3,3 В, не 5 В**. Не подавать на него питание 5 В.
Номера взяты из схемы, а не задают расположение слева направо: перед монтажом
сверить контакт 1, маркировку и ориентацию реального разъёма.

Панель получает стабилизированные 5 В через предусмотренный вход питания,
например USB-C. Вывод 3,3 В и питание согласователя не используются для питания
всей панели. Подключение и переключение проводов выполняются при выключенном
питании; проверяются также режимы с питанием только одной из плат.

## Прошивка и работа — раздельные режимы

Порядок из Example 7 руководства Elecrow для 7″ панели:

1. Отключить внешний UART от панели перед загрузкой прошивки.
2. Подключить USB-кабель к компьютеру и загрузить прошивку.
3. Выключить питание и подключить внешнее UART-устройство обратно.
4. Подать питание панели и проверить обмен с внешним устройством.

Во время работы с Arduino не использовать USB-последовательную связь панели
как второй независимый канал. Для рабочего стенда использовать питание без
передачи USB-данных; USB Arduino можно оставить отдельным каналом диагностики.
Если обновляется Arduino, межконтроллерную связь также разъединить на время
прошивки и проверить восстановление сессии после повторного подключения.

Питание через USB при использовании внешнего UART предусмотрено примером
Elecrow. Кабель только с питанием исключает передачу от компьютера, но сам
по себе не отключает выход CH340C внутри панели.

## Правила написания прошивки

1. Начальная настройка Smart Mixer — 19200 бод, SERIAL_8N1 на обеих платах.
   Это выбор нашего проекта, а не обязательная скорость Elecrow.
2. На CrowPanel явно назначать RX=44 и TX=43. На UNO использовать Serial1
   на D0/D1; USB Serial UNO оставить для диагностического текста.
3. У GPIO43/44 должен быть один программный владелец. Не инициализировать
   одновременно Serial/Serial0 и другой HardwareSerial на этих же контактах.
   Номер аппаратного UART и надпись UART0 на разъёме — разные вещи: выводы
   можно переназначить программно, но дорожки к CH340 от этого не исчезают.
4. В рабочем режиме через межконтроллерный UART передавать только кадры
   протокола. Убрать с этого канала отладочные Serial.print/printf и
   автоматический вывод логов библиотек/core. Диагностику выводить на экран,
   хранить в счётчиках или передавать определёнными протоколом сообщениями.
5. Учитывать загрузочные сообщения и reset ESP32: входной парсер должен
   игнорировать мусор, а управляющие команды разрешаются только после
   согласования версии, новой сессии и получения состояния Arduino.
6. Читать UART порциями без ожидания полной строки. Использовать ограниченные
   RX/TX-буферы, контроль длины, CRC и тайм-ауты из ../docs/PROTOCOL.md. Проверка CRC
   не заменяет проверку аргументов и допустимости операции.
7. Callback кнопки LVGL только ставит запрос в очередь. Не ждать ACK/DONE
   внутри обработчика касания, не обращаться к LVGL из UART ISR/callback.
   Объекты интерфейса обновлять из контекста UI по модели состояния.
8. Обслуживание UART не должно задерживать lv_timer_handler(). Сохранить
   рабочую RGB-конфигурацию: два framebuffer по 768000 байт, RGB565,
   LV_DISPLAY_RENDER_MODE_FULL, bounce buffers и переключение по VSYNC.
9. На Arduino при движении и дозировании продолжать обработку UART, STOP и
   контроля связи. Блокирующие homing/перемещение нужно заменить до включения
   удалённого управления механизмами.

## Что проверять при первом запуске

Сначала проверить простой двусторонний обмен без исполнительных нагрузок.
Проверить уровни на ESP RX, работу согласователя, ошибки кадров и CRC,
потерю связи и перезапуск каждой стороны. При обмене одновременно нажимать
кнопки и обновлять интерфейс: рябь, зависания и VSYNC timeout недопустимы.

На схеме Rev3 CH340C питается от общей 3V3 и связан с UART через R71/R72
по 470 Ом. На форуме Elecrow для старых плат производитель советовал заменить
22 Ом на 470 Ом при проблемах RX. В той же теме есть жалоба пользователя
Rev3 с 470 Ом на конкретный преобразователь RS485. Поэтому наличие резисторов
не доказывает совместимость любого внешнего передатчика или согласователя.

При неверных уровнях или потерях данных сначала проверять монтаж, питание,
согласователь и сигналы измерением. Не пытаться исправить электрическую
проблему изменением CRC, задержками, бесконечными повторами или настройками LVGL.
Перепайка резисторов, изоляция CH340 либо отдельный UART рассматриваются только
по результатам проверки; штатное подключение не объявляется неработоспособным
заранее.
