# Smart Mixer — краткая инструкция

Тестовый стенд проекта автоматизированного приготовления напитков. Arduino
управляет шаговым двигателем через A4988 и одним перистальтическим насосом
12 В через MOSFET-модуль.

## Комплектующие

- Arduino UNO R4 Minima;
- энкодер KY-040 с кнопкой;
- драйвер шагового двигателя A4988 и шаговый двигатель;
- перистальтический насос 12 В;
- MOSFET-модуль с выводами `VIN`, `OUT`, `GND`, `TRIG/PWM`;
- блок питания 12 В;
- защитный диод для насоса;
- электролитический конденсатор `47–100 мкФ`, не менее `25 В`.

## Распиновка Arduino

| Arduino | Назначение |
|---|---|
| `D2` | `CLK` энкодера |
| `D3` | `DT` энкодера |
| `D4` | `STEP` A4988 |
| `D5` | `DIR` A4988 |
| `D6` | `ENABLE` A4988 |
| `D7` | `TRIG/PWM` MOSFET-модуля |
| `D8` | `SW` кнопки энкодера |
| `D9` | верхний концевой выключатель |
| `5V` | питание логики |
| `GND` | общая земля |

## Энкодер

```text
KY-040 CLK → Arduino D2
KY-040 DT  → Arduino D3
KY-040 SW  → Arduino D8
KY-040 VCC → Arduino 5V
KY-040 GND → Arduino GND
```

Кнопка энкодера замыкает `SW` на `GND`.

## A4988

```text
A4988 STEP   → Arduino D4
A4988 DIR    → Arduino D5
A4988 ENABLE → Arduino D6
A4988 VDD    → Arduino 5V
A4988 GND    → общий GND
A4988 VMOT   → +12 В
A4988 GND    → 12 В-
```

`RESET` и `SLEEP` соединяются вместе и подключаются к `5V`.
`MS1`, `MS2`, `MS3` подключаются к `GND` для полного шага.

```text
одна обмотка двигателя   → 1A и 1B
вторая обмотка двигателя  → 2A и 2B
```

Между `VMOT` и силовым `GND` A4988 устанавливается конденсатор:

```text
плюс конденсатора  → VMOT / +12 В
минус конденсатора → GND / 12 В-
```

Не подключать и не отключать двигатель при включённом питании. Ограничение
тока A4988 необходимо настроить под конкретный двигатель.

## Насос и MOSFET-модуль

```text
12 В +       → VIN+
12 В -       → VIN-
насос +      → OUT+
насос -      → OUT-
Arduino D7   → TRIG/PWM
Arduino GND  → GND модуля
```

Земля Arduino, `GND` MOSFET-модуля и минус источника 12 В должны быть общими.
Насос нельзя питать от вывода `5V` Arduino.

Защитный диод подключается параллельно насосу:

```text
катод диода, сторона с полоской → насос+ / OUT+
анод                          → насос- / OUT-
```

Диод не ставится последовательно. Он гасит выброс напряжения при выключении
двигателя насоса и защищает MOSFET.

## Запуск программы

1. Открыть `smart_mixer.ino` в Arduino IDE 2.
2. В Boards Manager установить `Arduino UNO R4 Boards`.
3. Выбрать `Arduino UNO R4 Minima` и порт Arduino.
4. Нажать **Verify**, затем **Upload**.
5. Открыть Serial Monitor на скорости `115200 baud`.

## Текущий сценарий

- при включении выполняется homing вверх до верхнего концевика;
- один щелчок энкодера делает один шаг двигателя;
- вращение вправо считается движением вверх и блокируется на концевике;
- вращение влево позволяет двигаться вниз;
- удержание кнопки энкодера включает насос;
- отпускание кнопки выключает насос;
- встроенный LED Arduino горит при активном верхнем концевике.

Концевик подключается по схеме `COM → GND`, `NC → D9`, `NO` не подключается.
При такой схеме нажатый концевик размыкает цепь и определяется программой как
активный.
