# SmartMixerProtocol

Общий модуль C++11 для обеих прошивок. Не зависит от Arduino, LVGL или
операционной системы; не использует динамическую память.

Содержит формат кадра, CRC, codec/parser, ограниченную очередь Transport и
диагностические DiagnosticClient/DiagnosticServer. Платформенные адаптеры
открывают UART; общий код работает с интерфейсами чтения/tryWrite().
Физические операции и их защита от повторного выполнения не реализованы.

API находится в `src/SmartMixerProtocol.h`, пространство имён —
`smart_mixer::protocol`.

- `encode()` формирует законченный кадр без NUL; передавать ровно `written`
  байт и только при результате true.
- `Parser::feed()` получает по одному байту и текущее время в миллисекундах.
  Использовать выходной Packet только при `Result::Frame`.
- `Parser::tick()` вызывается также при пустом UART для обработки тайм-аута.
- `Parser::reset()` сбрасывает частичный пакет, сохраняя счётчики.
- `Parser::counters()` предоставляет локальную диагностику.

Каждому входному потоку нужен отдельный экземпляр Parser. Вызовы одного
экземпляра сериализуются владельцем: потокобезопасность и ISR-вызовы не
предусмотрены. Packet копируется при успешном разборе, поэтому его можно
передать в ограниченную очередь следующего слоя.

Библиотека подключена через `symlink://../shared/SmartMixerProtocol` к CrowPanel
и окружению `uart_diagnostics` Arduino. Обычная сборка `uno_r4_minima`
с прежними механическими командами пока не использует протокол.

Transport обрабатывает до 64 RX-байт и до 32 TX-байт за вызов; очередь — 4 кадра.
DiagnosticClient имеет один ожидающий запрос, проверяет заголовок и содержимое
ответа, устанавливает сессию, опрашивает статус и восстанавливает соединение.
DiagnosticServer принимает только HELLO/OPEN/PING/GET_STATUS и выдаёт read-only
снимок. Ему не передаются функции управления оборудованием.
