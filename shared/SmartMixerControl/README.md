# Исполнитель слоёного напитка

`RecipeExecution.h` — C++11-модель без Arduino/LVGL и I/O. Принимает объёмы,
расчётные длительности физических насосов, выбор первого насоса и общую таблицу
«суммарный объём → положение штока». Возвращает требуемый физический насос
и направление одного микрошагового импульса; адаптер владеет GPIO и датчиком.

Цикл: верхняя точка калибровки → первый слой без движения → опускание к
первому слою → второй слой с подъёмом по суммарному объёму → возврат к краю.
FIRST/SECOND — порядковые слои; они могут включать насосы как 1→2, так и 2→1.
При смене порядка объёмы и длительности сохраняют связь с физическим насосом.
При отмене/ошибке оба насоса выключены, автоматического возврата нет.
Heartbeat и пределы времени действуют на всех активных фазах; арифметика
времени учитывает rollover uint32.

Arduino-адаптер: `motion_controller/include/desktop_recipes.hpp`, только
`desktop_usb`. Тесты модели: `desktop_controller/src/test_recipes.cpp`.
Это отдельный исполнитель рецепта; сервисные homeUp/moveActuator остаются
блокирующими, а интеграция с кадрированным UART-протоколом ещё предстоит.
