# Общий интерфейс Smart Mixer

`src/MixerUi.*` — экраны LVGL 9.2.2 для 800×480, без Arduino, ESP-IDF, SDL,
POSIX и serial I/O. `Command` содержит логическое действие и параметры;
callback передаёт его адаптеру. Методы `setConnection/setStatus/setLog`
обновляются из UI-контекста, не из ISR или фонового транспорта.

Главный экран ведёт в каталог/приготовление, редактор, прокачку и промывку
и сервисный режим. Названия ингредиентов приходят через `setChannelNames`,
их сохранение выполняет адаптер (`ChannelHandler`).
`Recipe`/`RecipeHandler` отделяют экраны от хранения и приготовления;
ПК сохраняет каталог в `RecipeStore`, а команды выполняет USB-адаптер.

Сейчас библиотека подключена к `desktop_controller/` через CMake.
CrowPanel пока сохраняет свой диагностический экран. Позже эта библиотека
подключается как PlatformIO symlink dependency, а её команды — к UART-адаптеру.
Проверка параметров и допустимости действия обязательна в адаптере и Arduino.

Числовые поля — `NumericInput` на основе `lv_textarea`, с единым разбором текста
для кнопок `−/+` и отправки команд. Не возвращать `lv_spinbox` для прямого
клавиатурного ввода в LVGL 9.2.2: его обработка KEY вместе с textarea приводила
к повторной вставке символов и расхождению текста со внутренним числом.

`mixer_font_16.c` — переносимый растровый шрифт DejaVu Sans 16 px, ASCII,
кириллица U+0400–045F и длинное тире. Генерируется `lv_font_conv`, команда
сохранена в заголовке файла. Сжатие отключено для совместимости с конфигурацией
CrowPanel. Лицензия исходного шрифта: `FONT_LICENSE.txt`.
