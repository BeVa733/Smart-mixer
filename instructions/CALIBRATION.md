# Калибровка насосов

## Результаты коллеги

| Насос | Пин | Производительность |
|---|---:|---:|
| 1 | `D7` | `1.364 мл/с` |
| 2 | `D10` | `1.197 мл/с` |

В рабочем устройстве коэффициенты хранятся в EEPROM Arduino и используются
для дозирования заданного объёма. EEPROM относится к конкретной плате и не
заполняется самой прошивкой из репозитория.

Чтобы записать результаты коллеги без нового замера, после загрузки прошивки
отправь в Serial Monitor:

```text
c1 27.27
c2 23.94
```

## Калибровка через OLED

1. В главном меню выбрать `CALIBRATION`.
2. Коротко нажать кнопку энкодера.
3. Выбрать пункт:
   - `P1 PRIME` / `P2 PRIME` — прокачка трубки до появления жидкости;
   - `P1 20 SEC` / `P2 20 SEC` — точный замер производительности;
   - `P1 50 ML` / `P2 50 ML` — проверка дозирования по сохранённому коэффициенту.
4. Для запуска нажать кнопку энкодера ещё раз.
5. Для остановки прокачки нажать кнопку повторно.
6. Для выхода из режима сделать двойное нажатие.

## Как получить новый коэффициент

1. Подготовить воду, весы и отдельную ёмкость.
2. Выполнить `PRIME`, чтобы в трубке не осталось воздуха.
3. Поставить пустую ёмкость на весы и обнулить вес.
4. Запустить `P1 20 SEC` или `P2 20 SEC`.
5. После автоматической остановки записать массу воды в граммах.
6. В Serial Monitor на скорости `115200` отправить команду:

```text
c1 27.3
```

или для второго насоса:

```text
c2 23.9
```

Для воды граммы примерно равны миллилитрам. Программа делит полученное
значение на 20 секунд, записывает результат в EEPROM и сразу применяет его.

Например:

```text
27.3 г / 20 с = 1.365 мл/с
```

После этого запустить соответствующий пункт `P1 50 ML` или `P2 50 ML` и
проверить фактический объём. При необходимости повторить замер и отправить
новое значение.

Для аварийной остановки насоса можно отправить в Serial Monitor:

```text
s
```

Перекалибровка нужна при замене трубки, изменении жидкости, высоты ёмкости
или напряжения питания.
