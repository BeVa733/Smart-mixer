# Проверка протокола

## Тесты общего модуля на компьютере

Нужны CMake и C++11-компилятор. Из корня репозитория:

```sh
cmake -S tests/protocol -B /tmp/smart-mixer-protocol-build -DENABLE_SANITIZERS=ON
cmake --build /tmp/smart-mixer-protocol-build
ctest --test-dir /tmp/smart-mixer-protocol-build --output-on-failure
```

ASan/UBSan включаются опцией ENABLE_SANITIZERS. В средах с ограничениями ptrace
LeakSanitizer может требовать запуска вне песочницы. Для обычной сборки без
санитайзеров использовать `-DENABLE_SANITIZERS=OFF`.

Проверяются независимые эталонные CRC и кадры, все поддерживаемые TYPE,
фрагментация входа на каждой границе, несколько кадров подряд, мусор,
некорректные числа/поля/CRC, границы буферов, неоконченные строки, восстановление
по @, тайм-аут и переполнение millis(). Проверка случайного потока проходит
100000 байт с регулярной вставкой корректных кадров.

На ошибке выходной Packet должен остаться прежним. Кодировщик при недостатке
места возвращает false и written=0, не изменяя выходной буфер.

## Предстоящие тесты сессий и операций

Уже добавлен `link_tests`: симуляция двух контроллеров с побайтовой передачей,
потерей первого ответа, обрывом каждого направления, заблокированным TX,
reset сервера/клиента, истечением lease и переполнением millis(). Проверяются
повторный OPEN, старые ответы, строгие поля STATUS, переполнение TX-очереди
и отказ во всех исполнительных командах. Эти host-тесты проходят с ASan/UBSan,
но не заменяют проверку FSP-драйвера, электрических уровней или реального LVGL.

До добавления физических операций остаются проверки:

- Несовместимая версия и неверная сессия блокируют команды.
- Потеря ACK или DONE не вызывает повторного действия.
- Тот же ID с другими аргументами отклоняется.
- Старый ID вне истории не запускается заново.
- Перезапуск каждой стороны отменяет старую сессию.
- После неопределённого результата налива нет автоматического повторения.

## Предстоящие стендовые тесты

1. Проверить штатное подключение по [правилам USB/UART](../display_controller/UART_RULES.md),
   уровни и согласователь; TX/RX подтверждаются измерением и при необходимости
   логическим анализатором.
2. Без исполнительных нагрузок проверить двусторонний обмен и восстановление
   после отключения каждой сигнальной линии и reset каждой платы.
3. Проверить частые касания при обновлении STATUS: нет ряби, VSYNC timeout,
   переполнения UART или блокировки UI.
4. Проверить STOP и link timeout во время HOME, MOVE, DOSE и PRIME.
5. Проверить пределы привода, ошибки концевика и отказ в DOSE без калибровки.
6. С водой проверить потерю ответов при дозировании: команда с прежним ID
   физически выполняется один раз в рамках сессии.
7. Зафиксировать измеренное время реакции, число кадров/ошибок, версии прошивок
   и условия питания. Проверить загрузку через USB с отключённым внешним UART.

Тесты без оборудования не подтверждают электрическую совместимость или
время остановки реального привода.
