## Установленное ограничение подключения

На схеме CrowPanel Basic Rev3 J10 подключён к UART0. RXD0 соединён с TXD
CH340C через R72=470 Ом, TXD0 — с RXD CH340C через R71=470 Ом. Следовательно,
при прямом подключении Arduino TX к J10 RX возникают два передатчика на
одной линии. Закрытие монитора или переназначение HardwareSerial этого не
устраняет. При этом Elecrow предусматривает использование внешнего UART:
отключить его при прошивке, затем подключить обратно и питать панель через USB.
Сначала проверяется этот штатный вариант с согласованием уровней. Переделка
платы не считается обязательной. Правила подключения и кода:
[UART_RULES.md](../display_controller/UART_RULES.md).

## Ближайшая последовательность

1. Проверить штатный UART GPIO43/44 через согласователь, раздельно с
   USB-прошивкой/отладкой. Измерить уровни и проверить оба направления.
2. Добавить ограниченные RX/TX-адаптеры для Arduino и ESP32 и подключить
   общую библиотеку в оба platformio.ini.
3. Реализовать установление сессии, PING и GET_STATUS. Управляющие команды
   пока недоступны.
4. Добавить экран проверки связи, проверить реальные пакеты одновременно с
   быстрыми касаниями и перерисовкой LVGL.
5. Продолжить этапы 6–12 по таблице.
