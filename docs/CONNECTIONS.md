# Smart Mixer — подключения

## Arduino UNO R4 Minima

| Пин Arduino | Назначение |
|---|---|
| `D2` | `CLK` KY-040 |
| `D3` | `DT` KY-040 |
| `D4` | `STEP` TMC2209 |
| `D5` | `DIR` TMC2209 |
| `D6` | `EN` TMC2209 |
| `D7` | `TRIG/PWM` насоса 1 |
| `D8` | `SW` кнопки KY-040 |
| `D9` | верхний концевик |
| `D10` | `TRIG/PWM` насоса 2 |
| `5V` | питание логики |
| `GND` | общая земля |

## Питание

```text
12V + → VM TMC2209
12V + → VIN+ MOSFET-модулей
12V − → силовой GND TMC2209
12V − → VIN− MOSFET-модулей

12V + → VIN Arduino
12V − → GND Arduino
```

`GND` Arduino, TMC2209 и MOSFET-модулей должны быть общими.

В текущей тестовой сборке Arduino питается через `VIN` от источника `12V`.
Не подавать `12V` на пин `5V`.

## Сенсорный дисплей CrowPanel Rev3

Дисплей работает на собственном ESP32-S3 и прошивается отдельным проектом
[`display_controller`](../display_controller/README.md). OLED SSD1306 удалён из
прошивки Arduino; пины `A4` и `A5` для него больше не используются.

Связь CrowPanel с Arduino по UART пока не реализована. Общий формат пакета
и границы ответственности описаны в [PROTOCOL.md](PROTOCOL.md), правила
USB/UART — в [UART_RULES.md](../display_controller/UART_RULES.md), правила дисплея — в
[`DISPLAY_LVGL_RULES.md`](../display_controller/DISPLAY_LVGL_RULES.md).

### UART0: проверенная схема Basic Rev3

Источник — официальный EAGLE-файл
[`CrowPanel ESP32 Display-7.0-inch-V3.0-20240420.sch`](https://github.com/Elecrow-RD/CrowPanel-7.0-HMI-ESP32-Display-800x480/blob/c9799dba5a382b7f6b7fadcf754142dea595029b/Eagle_SCH%26PCB/V3.0/CrowPanel%20ESP32%20Display-7.0-inch-V3.0-20240420.sch),
commit `c9799dba5a382b7f6b7fadcf754142dea595029b`.
По именам цепей и pinref в схеме:

| Контакт J10 | Цепь | Назначение со стороны CrowPanel |
|---|---|---|
| 1 | UART0_RXD0 | RX, ESP32-S3 GPIO44 |
| 2 | UART0_TXD0 | TX, ESP32-S3 GPIO43 |
| 3 | 3V3 | 3,3 В; это не контакт питания 5 В |
| 4 | GND | Земля |

Номера контактов взяты из схемы. Положение контакта 1 на реальном разъёме
требует сверки маркировки/ориентации; таблица не задаёт порядок «слева направо».

В этой же схеме U6=CH340C питается от общей 3V3:

```text
ESP TXD0 ── R71 470 Ом ── RXD CH340C
ESP RXD0 ── R72 470 Ом ── TXD CH340C
```

Следовательно, подключение Arduino TX к J10/1 создаёт общую линию с выходом
TXD CH340C. Закрытие Serial Monitor и отключение USB-кабеля не гарантируют
отключения этого выхода: U6 питается от 3V3 самой панели. Переназначение
HardwareSerial на тех же выводах также не разрывает электрическое соединение.

Однако внешний UART предусмотрен производителем штатно: Elecrow предписывает
отключать внешнее UART-устройство перед прошивкой, а после загрузки подключать
его обратно и питать панель через USB. Поэтому сначала проверяется штатный
вариант с разделением режимов прошивки и обмена. Обязательная изоляция CH340
или переход на другие GPIO заранее не требуются. При проблемах проверяются
уровни и согласователь; подробнее — [правила USB/UART](../display_controller/UART_RULES.md).

### Согласование с UNO R4 Minima

UNO использует `Serial1`: D0/RX и D1/TX. USB Serial остаётся диагностическим.
Её логика — 5 В, логика ESP32 — 3,3 В. Arduino TX нельзя подключать напрямую
к ESP RX. Для начального стенда запланирован BSS138:

```text
Arduino D1/TX → HV1 → LV1 → ESP RX GPIO44
ESP TX GPIO43 → LV2 → HV2 → Arduino D0/RX
HV → опорные 5 В, LV → опорные 3,3 В
GND Arduino ↔ GND преобразователя ↔ GND CrowPanel
```

Проверка начинается с 19200 бод, 8N1, коротких проводов. Работоспособность
конкретного BSS138-модуля на UART подтверждается измерениями и проверкой
ошибок. Опорное питание преобразователя не используется для питания панели;
CrowPanel получает отдельные стабилизированные 5 В. При тестировании
проверяются также состояния при отключении питания одной из плат.

## Энкодер KY-040

```text
CLK → D2
DT  → D3
SW  → D8
VCC → 5V
GND → GND
```

Кнопка замыкает `SW` на `GND`.

## BIGTREETECH TMC2209 V1.3

```text
STEP → Arduino D4
DIR  → Arduino D5
EN   → Arduino D6
VDD/VIO → Arduino 5V
оба GND → общий GND Arduino
VM   → +12V
GND рядом с VM → 12V−
```

```text
MS1 → GND
MS2 → GND       (1/8 шага для TMC2209 в автономном STEP/DIR режиме)
CLK → GND       (внутренний тактовый генератор)
```

```text
A1 + A2 → одна обмотка двигателя
B1 + B2 → вторая обмотка двигателя
```

`RX`, `TX` или `PDN` (в зависимости от маркировки конкретной ревизии),
`DIAG`, `INDEX` и `VREF` к Arduino не подключать. В этой прошивке используется
только режим STEP/DIR, без UART и sensorless homing. `VREF` нужен только как
тестовая точка для измерения и регулировки тока.

Если два дополнительных вывода `DIAG/INDEX` или `VREF` загнуты и попадают в
макетную плату, не вставляй их в соседние дорожки: вынь их из макетки, отогни
или изолируй термоусадкой. Сам модуль лучше подключить через отдельные гнёзда
или переходник, чтобы эти выводы физически ни с чем не замкнулись.

Конденсатор `100 мкФ` ставится непосредственно возле драйвера:

```text
конденсатор + → VM
конденсатор − → силовой GND
```

Не вставлять и не вынимать TMC2209 при подключённых 12 В или USB. После замены
A4988 старую таблицу положений штока нужно собрать заново командой `hcal start 1`
или `hcal start 2`: теперь координаты считаются в микрошаговых импульсах.



## MOSFET-модуль и насос

Для каждого модуля с выводами `VIN+`, `VIN−`, `OUT+`, `OUT−`, `GND`,
`TRIG/PWM`:

```text
12V +       → VIN+
12V −       → VIN−
насос +     → OUT+
насос −     → OUT−
Arduino GND → GND
```

Управление:

```text
насос 1: TRIG/PWM → D7
насос 2: TRIG/PWM → D10
```

Защитный диод для каждого насоса подключается параллельно:

```text
катод, полоска → насос+
анод           → насос−
```

## Верхний концевик

Используется схема с нормально замкнутым контактом:

```text
COM → GND
NC  → D9
NO  → не подключать
```
