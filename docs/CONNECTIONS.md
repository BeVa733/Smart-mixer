# Smart Mixer — инструкция по подключению

Подключать провода при выключенном питании.

## 1. Блок питания 12 В

| Откуда | Куда |
|---|---|
| Блок питания 12 В, `+` | Arduino `VIN` |
| Блок питания 12 В, `−` | Arduino `GND` |
| Блок питания 12 В, `+` | TMC2209 `VM` |
| Блок питания 12 В, `−` | TMC2209 силовой `GND` возле `VM` |
| Блок питания 12 В, `+` | `VIN+` обоих MOSFET-модулей |
| Блок питания 12 В, `−` | `VIN−` обоих MOSFET-модулей |
| Блок питания 12 В, `+` | DC/DC 12→5 В, `IN+` |
| Блок питания 12 В, `−` | DC/DC 12→5 В, `IN−` |

Arduino, CrowPanel, преобразователь уровней, TMC2209 и MOSFET-модули соединить общей землёй.

**12 В подавать только на указанные входы 12 В. На Arduino `5V`, CrowPanel и UART их не подавать.**

## 2. DC/DC 12→5 В и разъём USB-A «мама»

| Контакт | Куда |
|---|---|
| DC/DC `IN+` | Блок питания `+12 В` |
| DC/DC `IN−` | Блок питания `12 В −` |
| DC/DC `OUT+ / +5V` | USB-A «мама», `VBUS / +5V` (контакт 1) |
| DC/DC `OUT− / GND` | USB-A «мама», `GND` (контакт 4) |
| USB-A «мама», `D−` и `D+` (контакты 2 и 3) | Не подключать |
| USB-A «мама» | Кабель USB-A → USB-C → разъём питания CrowPanel |

Перед подключением дисплея выставить и проверить на USB-A **5 В**. Выход — не менее 2 А; выбранный DC/DC — до 3 А. Контакты USB-A сверять по маркировке разъёма, а не по положению слева направо.

## 3. Преобразователь логических уровней BSS138: 5 В ↔ 3,3 В

| Контакт BSS138 | Куда |
|---|---|
| `HV` | Arduino `5V` |
| `LV` | CrowPanel `J10/3 — 3V3` |
| Все выводы `GND` | Общая земля |
| `HV1` | Arduino `D1/TX` |
| `LV1` | CrowPanel `J10/1 — RX, GPIO44` |
| `HV2` | Arduino `D0/RX` |
| `LV2` | CrowPanel `J10/2 — TX, GPIO43` |
| `HV3/LV3`, `HV4/LV4` | Не подключать |

`HV1↔LV1` и `HV2↔LV2` соединены внутри модуля. Arduino TX напрямую с CrowPanel RX не соединять.

## 4. Дисплей CrowPanel Basic 7″ Rev3

Питание: USB-C от DC/DC через USB-A, как в разделе 2. Разъём UART `J10`: подключить к преобразователю уровней по таблице раздела 3; `J10/4 — GND` соединить с общей землёй.

**`J10/3` — 3,3 В.** Номера контактов сверять с маркировкой платы. Перед USB-прошивкой отключать внешние сигнальные провода UART от панели.

| Контакт KY-040 | Куда |
|---|---|
| `CLK` | Arduino `D2` |
| `DT` | Arduino `D3` |
| `SW` | Arduino `D4` |
| `VCC / +` | Arduino `5V` |
| `GND` | Общая земля |

## 6. Драйвер BIGTREETECH TMC2209 V1.3

| Контакт TMC2209 | Куда |
|---|---|
| `STEP` | Arduino `D7` |
| `DIR` | Arduino `D5` |
| `EN` | Arduino `D6` |
| `VDD/VIO` — питание логики, по маркировке модуля | Arduino `5V` |
| Логический `GND` | Общая земля |
| `VM` | Блок питания `+12 В` |
| Силовой `GND` возле `VM` | Блок питания `12 В −` |
| `MS1` | Общая земля |
| `MS2` | Общая земля |
| `CLK` | Общая земля |
| `RX/TX/PDN`, `DIAG`, `INDEX`, `VREF` | Не подключать к Arduino и соседним дорожкам макетной платы |

### Шаговый двигатель

| Провода двигателя | Куда на TMC2209 |
|---|---|
| Два провода одной обмотки | `A1` и `A2` |
| Два провода другой обмотки | `B1` и `B2` |

### Конденсатор 100 мкФ возле драйвера

| Вывод конденсатора | Куда |
|---|---|
| `+` | TMC2209 `VM / +12 В` |
| `−` | TMC2209 силовой `GND` |

Двигатель и драйвер подключать или отключать только при снятых 12 В и USB-питании.

## 7. MOSFET-модули и насосы 12 В

| Контакт | Модуль насоса 1 | Модуль насоса 2 |
|---|---|---|
| `VIN+` | Блок питания `+12 В` | Блок питания `+12 В` |
| `VIN−` | Блок питания `12 В −` | Блок питания `12 В −` |
| `GND` | Общая земля | Общая земля |
| `TRIG/PWM` | Arduino `D8` | Arduino `D10` |
| `OUT+` | Насос 1, `+` | Насос 2, `+` |
| `OUT−` | Насос 1, `−` | Насос 2, `−` |

### Защитный диод — по одному на каждый насос

| Вывод диода | Куда |
|---|---|
| Катод — сторона с полоской | `+` соответствующего насоса / `OUT+` |
| Анод — сторона без полоски | `−` соответствующего насоса / `OUT−` |
