# Smart Mixer — подключения

## Arduino UNO R4 Minima

| Пин Arduino | Назначение |
|---|---|
| `D2` | `CLK` KY-040 |
| `D3` | `DT` KY-040 |
| `D4` | `STEP` TMC2209 |
| `D5` | `DIR` TMC2209 |
| `D6` | `EN` TMC2209 |
| `D7` | `TRIG/PWM` насоса 1 |
| `D8` | `SW` кнопки KY-040 |
| `D9` | верхний концевик |
| `D10` | `TRIG/PWM` насоса 2 |
| `5V` | питание логики |
| `GND` | общая земля |

## Питание

```text
12V + → VM TMC2209
12V + → VIN+ MOSFET-модулей
12V − → силовой GND TMC2209
12V − → VIN− MOSFET-модулей

12V + → VIN Arduino
12V − → GND Arduino
```

`GND` Arduino, TMC2209 и MOSFET-модулей должны быть общими.

В текущей тестовой сборке Arduino питается через `VIN` от источника `12V`.
Не подавать `12V` на пин `5V`.

## Сенсорный дисплей CrowPanel Rev3

Дисплей работает на собственном ESP32-S3 и прошивается отдельным проектом
[`display_controller`](../display_controller/README.md). OLED SSD1306 удалён из
прошивки Arduino; пины `A4` и `A5` для него больше не используются.

Связь CrowPanel с Arduino по UART пока не реализована. Распиновка и правила
работы дисплея описаны в
[`DISPLAY_LVGL_RULES.md`](../display_controller/DISPLAY_LVGL_RULES.md).

## Энкодер KY-040

```text
CLK → D2
DT  → D3
SW  → D8
VCC → 5V
GND → GND
```

Кнопка замыкает `SW` на `GND`.

## BIGTREETECH TMC2209 V1.3

```text
STEP → Arduino D4
DIR  → Arduino D5
EN   → Arduino D6
VDD/VIO → Arduino 5V
оба GND → общий GND Arduino
VM   → +12V
GND рядом с VM → 12V−
```

```text
MS1 → GND
MS2 → GND       (1/8 шага для TMC2209 в автономном STEP/DIR режиме)
CLK → GND       (внутренний тактовый генератор)
```

```text
A1 + A2 → одна обмотка двигателя
B1 + B2 → вторая обмотка двигателя
```

`RX`, `TX` или `PDN` (в зависимости от маркировки конкретной ревизии),
`DIAG`, `INDEX` и `VREF` к Arduino не подключать. В этой прошивке используется
только режим STEP/DIR, без UART и sensorless homing. `VREF` нужен только как
тестовая точка для измерения и регулировки тока.

Если два дополнительных вывода `DIAG/INDEX` или `VREF` загнуты и попадают в
макетную плату, не вставляй их в соседние дорожки: вынь их из макетки, отогни
или изолируй термоусадкой. Сам модуль лучше подключить через отдельные гнёзда
или переходник, чтобы эти выводы физически ни с чем не замкнулись.

Конденсатор `100 мкФ` ставится непосредственно возле драйвера:

```text
конденсатор + → VM
конденсатор − → силовой GND
```

Не вставлять и не вынимать TMC2209 при подключённых 12 В или USB. После замены
A4988 старую таблицу положений штока нужно собрать заново командой `hcal start 1`
или `hcal start 2`: теперь координаты считаются в микрошаговых импульсах.



## MOSFET-модуль и насос

Для каждого модуля с выводами `VIN+`, `VIN−`, `OUT+`, `OUT−`, `GND`,
`TRIG/PWM`:

```text
12V +       → VIN+
12V −       → VIN−
насос +     → OUT+
насос −     → OUT−
Arduino GND → GND
```

Управление:

```text
насос 1: TRIG/PWM → D7
насос 2: TRIG/PWM → D10
```

Защитный диод для каждого насоса подключается параллельно:

```text
катод, полоска → насос+
анод           → насос−
```

## Верхний концевик

Используется схема с нормально замкнутым контактом:

```text
COM → GND
NC  → D9
NO  → не подключать
```
